Boost.Asio 1.83 TCP服务端 API 速查

签名为便于学习而简化，采用普通lambda回调。模板文档中的DEDUCED表示返回类型由completion token决定；使用普通回调时调用表达式返回void，真正结果进入回调。

1. 事件循环

API参数返回/结果项目含义
boost::asio::io_context io;默认构造无需参数。构造函数无返回值。持有异步I/O服务和待执行handler；V1由一个I/O线程调用run()。
io.run()无。count_type：本次执行的handler数量。没有未完成工作或被stop()时返回。事件循环；异步操作的回调只会在正在运行io_context的线程上执行。
io.stop()无。void。请求事件循环尽快停止；不保证剩余handler都执行。
io.restart()无。void。run()正常返回后，如需再次运行必须先restart；有线程仍在run时不可调用。
boost::asio::post(io, fn)io为目标执行上下文；fn签名为void()。普通回调用法为void；任务稍后由io线程执行，不在post内部直接调用。CommandExecutor完成业务后，把响应安全投递回I/O线程。

2. 地址与监听

API参数返回/结果
tcp::endpoint(tcp::v4(), port)tcp::v4()选择IPv4；port是主机字节序端口，类型近似uint16_t。构造tcp::endpoint，地址为任意本地IPv4地址。
tcp::acceptor(io, endpoint, reuse_addr)事件上下文、监听endpoint；reuse_addr默认true。构造并完成open/bind/listen的acceptor；失败抛boost::system::system_error。
acceptor.open(protocol, ec)通常传endpoint.protocol()；ec接收错误。void；不抛异常版本通过ec报告结果。
acceptor.set_option(tcp::acceptor::reuse_address(true), ec)socket选项和错误码输出参数。void。
acceptor.bind(endpoint, ec)要绑定的本地地址/端口和错误码。void；常见错误是端口已占用或权限不足。
acceptor.listen(backlog, ec)backlog是内核待accept连接队列上限提示；可用socket_base::max_listen_connections。void。
acceptor.async_accept(handler)handler(error_code ec, tcp::socket socket)。立即返回；成功时回调获得新socket。每次完成后需要再次发起accept，停止中的operation_aborted除外。

3. Buffer、读取和写入

API参数返回/回调关键契约
asio::buffer(data, size)可写void*得到mutable_buffer；只读const void*得到const_buffer；size为字节数。返回轻量内存视图。不复制、不拥有内存；底层数组/string/vector必须活到异步回调结束，期间不能发生使地址失效的扩容或销毁。
socket.async_read_some(buffers, handler)可写buffer序列；handler(ec, bytes)。立即返回；成功回调给出这一次实际读取字节数。可能只读到请求的一部分；TCP没有消息边界。适合增量PacketCodec，不等于“读取一个包”。
asio::async_read(socket, buffers, handler)socket、可写buffer序列、handler(ec, bytes)。立即返回；默认填满给定buffer或遇到错误后完成。适合先精确读取固定长度包头，再按校验后的长度读取包体。同一socket上完成前不要启动第二个读取操作。
asio::async_write(socket, buffers, handler)socket、只读buffer序列、handler(ec, bytes)。立即返回；写完全部buffer或遇错后完成。底层可能多次部分发送。完成前不要并发启动另一个写操作；用SendQueue串行化。

4. 错误、连接信息和关闭

API参数返回/含义
if (ec)boost::system::error_code。true表示失败；ec.message()返回可读文本，ec.value()返回类别相关整数。逻辑分支优先比较asio::error::eof、operation_aborted等枚举，不只比较整数。
socket.is_open()无。bool：本地socket对象是否持有打开的底层socket；不证明对端仍在线。
socket.remote_endpoint(ec)错误码输出参数。返回tcp::endpoint；可取address()和port()用于日志。
socket.cancel(ec)错误码输出参数。void；请求取消关联的异步操作，回调通常以operation_aborted完成。
socket.shutdown(tcp::socket::shutdown_both, ec)关闭发送、接收或双向能力；ec接收错误。void；影响TCP方向状态，不释放本地socket句柄。
socket.close(ec)错误码输出参数。void；释放底层socket并取消未完成异步操作。关闭应设计为幂等状态机，而不是仅检查一次is_open()。

5. 第二阶段再加入

API用途返回/回调
steady_timer::expires_after(duration) + async_wait(handler)登录超时、读超时、心跳检测。expires_after返回被取消的等待数量；handler为void(error_code)。
signal_set(io, SIGINT, SIGTERM) + async_wait(handler)把进程停止信号接入正常异步关闭链路。handler为void(error_code, int signal_number)。
当前不学：strand、co_spawn/awaitable、多io_context、多I/O线程。V1只有一个I/O线程，先把Session、PacketCodec、SendQueue和关闭语义做对。
